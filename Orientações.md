# Orientações

Resumo do guia para criar um portfólio profissional como este com o Claude Code.

## Parte 1 · Preparação, do zero

- Como ter o Claude Code: assinatura do Claude e o app para desktop, na aba Code.
- Como criar a conta no GitHub, com a dica de escolher bem o nome de usuário, porque ele vira o endereço do site.
- Como instalar o Git e o GitHub CLI, no Windows e no Mac.
- Que materiais separar na pasta: currículo em PDF, foto e prints das recomendações.
- Como abrir a pasta no Claude Code e colar o prompt.

## Parte 2 · O prompt para colar

- **Como o Claude deve trabalhar:**
  - Lê o currículo primeiro.
  - Depois faz as perguntas.
  - Mostra a prévia e trabalha em rodadas de ajustes.
  - Só publica com aprovação.
- **As perguntas a responder durante a criação:**
  - Posicionamento e cargos buscados.
  - Principais resultados e casos.
  - O que não pode aparecer no site.
  - Método de trabalho, voluntariado, livros e projetos.
  - Recomendações, idiomas, estilo visual e foto.
  - Contatos, telefone no currículo, WhatsApp flutuante e nome de usuário no GitHub.
- **Regras de privacidade:**
  - Informações privadas nunca vão para o site.
  - O histórico do Git usa o e-mail "noreply" do GitHub.
  - O login no GitHub é sempre feito pela pessoa.
  - O Claude não inventa números.
  - Se o código de verificação do GitHub não chegar: abrir https://github.com/login/device, conferir o app GitHub Mobile e o e-mail (inclusive o spam), e tentar de novo.
- **Especificações técnicas:** todas as seções deste site, em formato de modelo. Vão do topo com foto e destaque do maior resultado até o carrossel de recomendações, o gráfico da trajetória com o voluntariado, a imagem de prévia para WhatsApp e LinkedIn e o crédito ao Claude Code no rodapé.
- **Publicação no GitHub Pages:** cada passo, incluindo conferir se o site está no ar depois de cada atualização.

## Dicas de quem já fez

- Mandar o feedback em listas, com prints.
- Reescrever com as próprias palavras o que não soar como você.
- Revisar cada número.
- Usar Ctrl+F5 para ver a versão nova.
